## 2. CORD v2 — Included

| Item | Detail |
|---|---|
| **Full Name** | Consolidated Receipt Dataset v2 |
| **HF Repo** | `naver-clova-ix/cord-v2` |
| **License** | ⚠️ TO VERIFY — check the official dataset card and applicable terms |
| **Original Size** | 1,000 receipt images |
| **Retained Size** | 946 records after excluding 28 records without an annotated total and 26 duplicate records |
| **Language** | Indonesian-origin dataset; many receipts contain English text |
| **Fields Retained** | `total` only |
| **Other Ground-Truth Fields** | `supplier`, `date`, and `invoice_number` are empty |
| **Citation** | Park et al., "CORD: A Consolidated Receipt Dataset for Post-OCR Parsing," 2019 |

**Annotation policy in v1.1:**

- `total` is extracted only from `total.total_price`.
- Records without an annotated total are excluded.
- `quality` is `unassessed`.
- `annotations.origin_language` is `id`.
- `annotations.label_version` is `v1.1`.

**Important licensing note:** Do not assume that public availability on Hugging Face grants commercial-use permission. Verify the dataset card, original source terms, and any applicable third-party restrictions before commercial distribution or use.

3. Preserve required attribution and license notices.
4. Check restrictions on redistribution and derivative works.
5. Review privacy and consent obligations for any future real-document data.
